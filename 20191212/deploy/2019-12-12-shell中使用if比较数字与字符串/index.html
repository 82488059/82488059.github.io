|浏览量:

记录shell中的数字与字符串比较操作用法

if的格式

注意格式:

空格一定要有，否则判断出错。

正确示例：


输出A=1
错误示例：

输出B=2

在shell中字符串与数值的比较方法不同

1、整数比较：

等于 -eq 或 =
不等于 -ne 或 <>
大于 -gt 或 >
大于等于 -ge 或 >=
小于 -lt 或 <
小于等于 -le 或 <=

2、字符串比较：

等于= 或 ==


不等于 !=

空串 -z

非空串 -n
